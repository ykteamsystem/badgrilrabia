# badgirilrabia — GitHub Pages
1. Replace `KULLANICI` in `index.html`, `robots.txt`, and `sitemap.xml` with your GitHub username.
2. Add your three photos in `images/` named `foto1.jpg`, `foto2.jpg`, `foto3.jpg`.
3. Create a GitHub repository named `badgirilrabia` and upload all files.
4. Repository Settings → Pages → Deploy from a branch → `main` / root.
5. Submit the sitemap in Google Search Console. Indexing/search visibility is not guaranteed or immediate.

Use photos you have permission to publish. If they show someone else, get their consent first.
